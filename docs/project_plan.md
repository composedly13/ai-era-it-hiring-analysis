# 연구 기획서 (요약)

전체 연구 기획서는 README.md를 참조하세요.

## 핵심 메시지

생성형 AI 시대의 IT 채용시장은 단순히 AI가 개발자를 대체하는 방향으로만 변하지 않는다.
뉴스 담론은 위기와 일자리 재편을 강조하지만, 실제 채용공고는 여전히 기본 개발역량과 실무 기술스택을 핵심으로 요구한다.

## 데이터 역할 분리

| 데이터 | 역할 | 시계열 |
|---|---|---|
| 워크넷 API | 국내 현재 실제 요구역량 | 현재 단면 |
| LinkedIn CSV | 글로벌 채용공고 단면 | 2023–2024 |
| 빅카인즈 뉴스 | 국내 담론 장기 시계열 | 2021–2026 |

## 연구 질문

- **RQ1** 현재 국내 IT 채용공고에서 가장 많이 요구되는 역량은?
- **RQ2** 글로벌 IT 채용공고에서 AI 관련 역량 요구는 어떻게 나타나는가?
- **RQ3** 국내 뉴스에서 IT 채용·개발자 담론은 2021–2026 어떻게 변했는가?
- **RQ4** 언론 담론과 실제 채용공고의 요구역량은 일치하는가?
- **RQ5** 채용공고 텍스트로 직무군을 분류할 수 있는가?
