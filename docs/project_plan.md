# 연구 기획서 (요약)

전체 연구 기획서는 README.md를 참조하세요. (상세 설계·분석별 산출물 명세는 별도 기획서 문서 참조)

## 핵심 메시지

생성형 AI 시대의 IT 채용시장은 단순히 AI가 개발자를 대체하는 방향으로만 변하지 않는다.
뉴스 담론은 위기와 일자리 재편을 강조하지만, 실제 채용공고는 여전히 기본 개발역량과 실무 기술스택을 핵심으로 요구한다.

## 데이터 역할 분리

| 데이터 | 역할 | 시계열 |
|---|---|---|
| 점핏·원티드 | 국내 현재 실제 요구역량 | 현재 단면(종료/과거 공고 불가) |
| LinkedIn CSV | 글로벌 채용공고 단면 | 2023–2024 (과거 포함) |
| 빅카인즈 뉴스 | 국내 담론 장기 시계열 | 2021–2026 |

## 연구 질문 (개정판)

- **RQ1** 현재 국내 IT 공고가 가장 많이 요구하는 역량은? (점핏·원티드)
- **RQ2** 글로벌 IT 공고의 요구역량·AI 역량은 어떻게 나타나는가? (LinkedIn)
- **RQ3** 국내 뉴스의 개발자 채용 담론은 2021–2026 어떻게 변했나? (뉴스)
- **RQ4** 언론 담론과 실제 요구역량은 일치하는가? — RQ4a 기술스택 간극(Spearman) + RQ4b 담론 프레임 지수
- **RQ5** 국내 vs 글로벌 요구역량 격차(lag)는 얼마나 되는가? (국내공고 × LinkedIn)
- **RQ6** (보조) 공고 텍스트로 직무군을 분류할 수 있는가?

## 데이터 소스

국내 채용공고는 **점핏·원티드 공개 JSON 엔드포인트 호출 + 직접 크롤링**으로 수집(API 활용 + 직접 수집 = 가산점). 현재 국내 통합 3,274건 확보.
