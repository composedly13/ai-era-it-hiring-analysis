# RQ4. 담론(뉴스) vs 현실(국내공고) 간극 분석

> **요약 한 줄.** 뉴스는 "AI·GPT·ChatGPT"를 외치지만 공고는 **Docker·React·MySQL·PyTorch**를 요구한다. ChatGPT 이후 담론↔현실의 순위상관 ρ는 **0.42 → 0.26 → 0.10** 으로 떨어졌다 — **시간이 갈수록 담론은 현실에서 멀어지고 있다.**

---

## 1. 데이터·방법론

| 항목 | 담론 (뉴스) | 현실 (국내공고) |
|---|---|---|
| 출처 | 빅카인즈 BIGKinds (51개 매체) | 점핏·원티드 활성 공고 |
| 시점 | **2026-01 ~ 2026-05** (동일 시점만, 시점 통제) | **2026-05** 단면 |
| 표본 | 7,348건 | 3,274건 |
| 단위 | 기사당 본문 멀티라벨 호명 | 공고당 요구역량 명시 |
| 토큰 | `tech_dictionary`로 canonical 추출 (동일 사전) | 동일 사전 (Validity Guardrail #3) |

**핵심 비교 단위.** 양쪽 모두 같은 기술스택 사전 — `tech_dictionary.py` 의 canonical 토큰 (Python, React, Docker, ChatGPT, PyTorch 등 약 250개) 으로만 비교한다. 뉴스 본문에서 추출된 canonical 토큰의 빈도 분포와, 공고 요구역량 필드의 canonical 토큰 빈도 분포를 직접 대조한다.

**Validity Guardrail (RQ4 한정).**
1. **공정 비교** — 뉴스 2026 / 공고 2026-05 동일 시점. before/after 비교는 별도(RQ4-d).
2. **비교 어휘 분리** — 기술스택 사전 토큰만 (위기·대체 같은 담론 프레임어는 RQ3-D에서 별도 분석).
3. **언어 통제** — 한국어↔영어 토픽 직접 비교 금지. canonical(영문) 토큰만 비교.
4. **비대칭 해석** — 뉴스는 "본문 멀티라벨 언급(보유율)", 공고는 "요구역량 명시(보유율)". 단위가 달라서 **"관측된 격차"** 로 해석하며, "실제 도구 도입률 차이"로 직역 금지.

**시점별 비교(RQ4-d) 통제.** 공고는 2026-05 단면으로 고정하고 **뉴스만 시점을 바꿔서** 비교 — `before ChatGPT (~2022-11)` / `after ChatGPT (2022-12~)` / `2026 동일 시점`. 즉 "공고가 변한 게 아니라 담론이 얼마나 현실에서 멀어졌는가" 를 본다.

## 2. 연구 가설

> **H2.** ChatGPT 출시(2022-11) 이후 뉴스 채용 담론은 실제 공고 요구역량과 점점 멀어졌을 것이다. 특히 **(a) 모호한 'AI' 호명 과잉**, **(b) 구체적인 ML/엔지니어링 역량은 담론에서 누락**, **(c) 시간이 갈수록 담론↔현실 Spearman ρ 약화** 가 동시에 관측될 것이다.

RQ3에서 발견한 8개 패턴(뉴스에 AI/ML 담론 60%, Tier D 'AI' 87%, 신입 담론 반토막 등)이 실제 공고와 어떻게 어긋나는지를 정량화한다.

### RQ4-a. 기술스택 순위 사분면 (`rq4_gap_index.png`) — 협업자 PR #8

2026 뉴스 7,348건 × 공고 3,274건. 양쪽 top 40 토큰 합집합 기준.

| 분류 | 정의 | 대표 토큰 |
|---|---|---|
| **공통** | 양쪽 모두 상위 / Δrank ∈ [-10, +10] | AI, AWS, Git, LLM, Python (LLM은 Δ=-8, 거의 공통) |
| **담론 과잉(뉴스>공고)** | Δrank ≤ -10 (뉴스가 공고보다 상위) | (RQ4-c 표 참조 — GPT·Copilot·Gemini 등) |
| **조용한 핵심(공고>뉴스)** | Δrank ≥ +10 (공고가 뉴스보다 상위) | **Docker, MySQL, REST API, TypeScript, Next.js, React, PyTorch, C++, TensorFlow, PostgreSQL** |

**Spearman ρ = 0.104 (p=0.39).** 양쪽에 등장한 70개 공통 토큰의 순위상관. **통계적으로 유의하지 않음** — 즉 뉴스 담론의 순위는 공고 요구 순위와 거의 무관하다.

**가장 큰 발견.** 공고 상위 30개 중 **AI/Python/AWS/Git 4개만 공통**, 나머지 26개는 **모두 "조용한 핵심"**. 뉴스 담론은 실무 스택을 거의 다루지 않는다.

### RQ4-d. 시점별 Spearman ρ (`rq4_period_spearman.png`) — **메인 발견**

공고는 2026-05로 고정. 뉴스 시점만 바꿔서 비교.

| 시점 | n (기사) | 공통 토큰 | Spearman ρ | p-value | 해석 |
|---|---:|---:|---:|---:|---|
| before ChatGPT (~2022-11) | 14,737 | 60 | **0.415** | 0.001 | 강한 양의 상관, 통계적 유의 |
| after ChatGPT (2022-12~) | 42,226 | 83 | **0.260** | 0.018 | 상관 약화, 유의 |
| 2026 (동일 시점) | 7,348 | 70 | **0.104** | 0.39 | **거의 무상관, 통계적으로 유의하지 않음** |

> ρ가 0.42 → 0.26 → 0.10 으로 떨어졌다. **이게 RQ4의 핵심 발견이다.**

**해석.**
- **2022년 이전**: 뉴스가 다루던 채용 기사는 "Java 개발자 부족", "데이터 사이언티스트 인기" 처럼 실제 공고와 어느 정도 정렬되어 있었다 (ρ=0.42).
- **ChatGPT 이후**: 뉴스 담론의 초점이 "ChatGPT가 개발자를 대체할까", "Copilot이 코딩을 바꾼다" 같은 **모델·도구 담론**으로 이동하면서 실제 공고가 요구하는 기술스택과의 정렬이 깨졌다 (ρ=0.26).
- **2026**: 뉴스는 거의 모든 IT 기사가 'AI'를 호명할 정도로 담론이 동질화되었고(RQ3-F: Tier D 87%), 실제 공고가 요구하는 다양한 실무 스택(Docker·React·PyTorch·Spring 등)과의 순위상관은 **통계적으로 무의미한 수준(0.10, p=0.39)** 으로 떨어졌다.

→ **담론과 현실은 시간이 갈수록 멀어지고 있다.** H2 가설을 강력히 지지.

(양수 = 뉴스 과잉 / 음수 = 공고 과잉, 단위 pp)

**5가지 핵심 패턴.**

1. **모든 직무에서 Tier D 'AI' 호명 과잉** (+14.7 ~ +71.3pp). 뉴스 기사들이 직무를 막론하고 'AI'를 끌어들인다.
2. **임베디드·보안 직무가 가장 큰 'AI' 담론 과잉**: 임베디드 +71.3pp, 보안 +69.1pp. 실제 임베디드 공고는 19%, 보안 공고는 26%만 'AI' 명시 — 뉴스가 부풀린 효과.
3. **AI/ML 직무의 Tier C 결손 -61.5pp** — RQ4 전체에서 가장 강력한 단일 격차. 공고는 PyTorch/MLOps/RAG/Fine-tuning 87% 요구하지만 AI/ML 관련 뉴스 기사 중 이런 구체 역량 호명은 26%. **뉴스가 'AI 인재 부족'을 외치지만 어떤 역량이 부족한지는 다루지 않는다.**
4. **풀스택 직무의 Tier A 결손 -21.9pp** — 풀스택 공고 28.6%가 Copilot/Cursor 명시, 뉴스 6.7%만. AI 코딩 도구의 실제 도입이 풀스택 직무에서 활발하지만 담론은 이를 따라오지 못함.
5. **모바일 직무의 Tier B 과잉 +23.7pp** — 모바일 관련 뉴스 25%가 ChatGPT/GPT 호명, 실제 모바일 공고 1.3%만. "ChatGPT가 모바일 앱을 바꾼다" 류 추상 담론이 모바일 공고 요구와 정반대.

## 4. 통합 발견 — 5가지 핵심 패턴

### Pattern A. **GPT·ChatGPT 도배 vs Docker·React 침묵**
뉴스 담론은 **고유명사(GPT, ChatGPT, Copilot, Claude, Gemini)** 에 집중. 공고가 요구하는 **인프라(Docker/Kubernetes)·DB(MySQL/PostgreSQL)·프론트(React/TypeScript)** 는 담론에서 통째로 누락 (RQ4-a, RQ4-c).

### Pattern B. **모호한 'AI' 호명 과잉, 구체 ML 역량 결손**
Tier D 'AI' Δ +36.4pp vs Tier C ML 역량 Δ -22.3pp. **뉴스는 'AI'를 외치고 PyTorch는 모른다** (RQ4-b).

### Pattern C. **담론↔현실은 시간이 갈수록 멀어진다**
Spearman ρ: before 0.42 → after 0.26 → 2026 0.10 (p=0.39). **ChatGPT 이후 격차 확대, 2026에는 무상관 수준** (RQ4-d).

### Pattern D. **모든 직무에서 'AI' 담론 과잉, 특히 임베디드·보안**
직무를 막론하고 뉴스의 Tier D 호명이 공고를 초과 (+14.7 ~ +71.3pp). 임베디드·보안 직무에서 가장 큼 — 뉴스가 직무 맥락과 무관하게 'AI'를 끌어들이는 경향 (RQ4-e).

### Pattern E. **AI/ML 직무에서 가장 큰 담론 결손**
AI/ML 공고는 Tier C(PyTorch·MLOps·RAG·Fine-tuning) 87.7% 요구. 뉴스 AI/ML 기사는 26.3%만 다룸. **"AI 인재 부족"을 외치는 담론은 어떤 역량이 필요한지는 알려주지 않는다** (RQ4-e).

## 5. 가설 H2 검증

| H2 하위 명제 | 결과 | 근거 |
|---|---|---|
| (a) 모호한 'AI' 호명 과잉 | ✓ 강력 지지 | Tier D Δ +36.4pp (RQ4-b) · 직무 무관 +14.7~+71.3pp (RQ4-e) |
| (b) 구체 ML/엔지니어링 역량 담론 결손 | ✓ 강력 지지 | Tier C Δ -22.3pp (RQ4-b) · AI/ML 직무 Tier C -61.5pp (RQ4-e) · PyTorch/TensorFlow 조용한 핵심 (RQ4-c) |
| (c) 시간이 갈수록 ρ 약화 | ✓ 강력 지지 | ρ 0.42 → 0.26 → 0.10, p값 0.001 → 0.018 → 0.39 (RQ4-d) |

**H2 종합: 강력 지지.** 세 하위 명제 모두 확인. 특히 (c)의 시점별 ρ 감소 추이는 단순한 cross-section 격차가 아니라 **시간에 따라 담론이 현실에서 멀어지는 동학(dynamics)** 을 보여준다.

## 6. 한계점

1. **단위 비대칭.** 뉴스=본문 멀티라벨 언급(보유율) vs 공고=요구역량 명시(보유율). 동일한 "%" 단위지만 의미가 다름. "관측된 격차" 로만 해석하며 "실제 도입률 차이" 로 직역 금지.
2. **공고 데이터 편향.** 점핏·원티드는 IT 전문 플랫폼 — 일반 종합 채용 사이트(잡코리아·사람인) 대비 기술스택 명시도가 높음. 즉 "Docker·React 침묵"은 일부 뉴스가 일반 채용 시장을 다루기 때문일 수 있음.
3. **뉴스 직무 매칭 보수성.** title 기반 멀티라벨이라 본문에서만 직무를 다룬 기사는 누락. 데이터·QA·모바일 직무는 뉴스 n<15 — 표본 부족.
4. **시점 통제 한계.** before/after 비교에서 공고는 2026-05 단면 고정. 2022년 공고 데이터가 없어 "2022년 담론은 그 시점 공고와도 정렬됐는가" 는 검증 불가. 다만 공고가 천천히 변한다고 가정하면 본 분석의 동학 해석은 유효.
5. **canonical 사전 의존성.** 뉴스 본문에서 추출되는 토큰은 사전에 등재된 약 250개로 한정. 사전에 없는 신생 도구(2026년 신규 출시)는 포착 안 됨.

## 7. RQ3 ↔ RQ4 연결

RQ3에서 뉴스 담론의 변화를 추적했다면, RQ4는 그 담론이 **실제 공고와 얼마나 어긋나는가** 를 측정.

| RQ3 발견 | RQ4 검증 결과 |
|---|---|
| 뉴스 AI/ML 담론 60% (RQ3-G-2) | 실제 공고 AI/ML 직무 16% — **44pp 과잉** |
| Tier D 'AI' 뉴스 87% (RQ3-F) | 공고 Tier D 51% → **Δ +36.4pp** (RQ4-b) |
| Tier B 모델·플랫폼 뉴스 13% (RQ3-F) | 공고 7.7% — **GPT/ChatGPT 도배 확인** (RQ4-c) |
| 웹 개발 담론 반토막 (RQ3-G) | 공고는 React/Next.js/Spring 핵심 — **조용한 핵심** (RQ4-c) |
| 신입 담론 반토막 (RQ3-I) | (별도 RQ — 본 문서 범위 밖) |

→ **RQ3에서 관측된 담론의 편향이 RQ4에서 모두 확인되었다.** 뉴스는 "AI 시대"를 외치지만 그 안에서 구체적인 직무·역량·도구는 거의 다루지 않는다.

## 9. 발표 핵심 메시지 제안

1. **"뉴스는 GPT를 외치고, 공고는 Docker를 원한다."** — 한 줄 헤드라인.
2. **ρ = 0.42 → 0.26 → 0.10.** — 시간이 갈수록 담론이 현실에서 멀어진다.
3. **모든 직무에서 'AI' 호명 과잉, 특히 임베디드 +71pp.** — 뉴스가 직무 맥락과 무관하게 'AI'를 끌어들임.
4. **AI/ML 공고는 PyTorch·MLOps 87% 요구, 뉴스는 26%만 다룸.** — 담론은 'AI 인재 부족'을 외치지만 어떤 역량이 필요한지는 알려주지 않음.
5. **시사점.** 채용 정보 소비자(취준생)는 뉴스 담론에 의존하면 실제 요구역량과 어긋난 준비를 할 위험. 정책·교육 측에서도 "AI 인재"를 외칠 게 아니라 구체 역량(PyTorch·MLOps·RAG)을 명시할 필요.
